# Testing References & Tool Guides

Comprehensive guides for testing tools, WordPress standards, and LightSpeedWP conventions.

## Reference Files

### jest-reference.md
Jest configuration and best practices:
- Configuration options (testMatch, collectCoverageFrom, moduleNameMapper)
- Coverage thresholds and enforcement
- Mock setup patterns
- Async test handling
- Transform configuration
- Common issues and solutions

### playwright-reference.md
Playwright testing patterns:
- Locator strategies (by ID, class, ARIA, text)
- Wait conditions and assertions
- Page object model pattern
- Visual testing setup
- Performance profiling
- Cross-browser configuration

### wordpress-standards.md
WordPress testing conventions:
- Block development standards
- Plugin testing requirements
- Theme testing checklist
- Hook and filter testing
- Database testing patterns
- WordPress-specific test utilities

### lefthook-setup.md
Lefthook pre-commit hook configuration:
- Installation per platform (macOS, Linux, Windows)
- Configuration structure
- Hook commands and globs
- Failure handling
- Performance optimization
- Debugging hooks

### theme-utils-reference.md
Theme-utils.mjs validation utilities:
- Adapted from WordPress core and Twenty Twenty-Five
- Theme attribute structure
- Block attribute validation
- Design token consistency checking
- Template hierarchy validation
- Custom validator implementation

## How to Use

1. Choose the reference relevant to your tool/topic
2. Find the section addressing your question
3. Reference examples and patterns
4. Apply to your project
