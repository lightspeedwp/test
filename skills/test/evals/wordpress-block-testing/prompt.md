# Eval: WordPress Block Testing Strategy

**Scenario:** Building a new WordPress block that needs comprehensive testing.

**Block Specifications:**
- Hero block with image, title, and CTA button
- Editable in block editor
- Responsive at mobile/tablet/desktop
- Must be WCAG 2.2 AAA accessible
- Uses theme.json design tokens
- Needs 100% test coverage

**Your Task:**
1. Create comprehensive testing strategy
2. Design 7-dimension testing matrix
3. Provide test templates for each dimension
4. Include accessibility checklist
5. Provide Playwright E2E test example

**Expected Output:**
- Complete 7-dimension testing strategy
- Jest test templates
- Playwright E2E test code
- Accessibility validation checklist
- Coverage target confirmation
