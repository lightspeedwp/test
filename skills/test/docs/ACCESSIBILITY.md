# WCAG 2.2 AAA Testing Guide

Accessibility testing requirements and checklist.

## WCAG 2.2 AAA Criteria

- **Color Contrast:** 7:1 ratio for normal text, 4.5:1 for large text
- **Keyboard Navigation:** All functionality available via keyboard
- **Screen Reader:** Proper ARIA labels and roles
- **Focus Indicators:** Visible focus on interactive elements
- **Motion:** Respects `prefers-reduced-motion`
- **Text Sizing:** Readable at 200% zoom

## Testing Checklist

- [ ] All interactive elements keyboard accessible
- [ ] Tab order logical and visible
- [ ] Form labels associated with inputs
- [ ] Images have alt text
- [ ] Color not sole means of conveying information
- [ ] Text content readable on mobile
- [ ] Focus visible on all interactive elements
- [ ] Reduced motion respected
