# Eval: Coverage Gap Analysis

**Scenario:** Jest coverage dropped from 90% to 75%. Need to identify gaps and create tests.

**Coverage Report Shows:**
- Total coverage: 75%
- Lines: 78%
- Branches: 65%
- Functions: 82%
- Statements: 76%

**Problem Areas:**
- Error handling paths untested
- Edge cases not covered
- Some utility functions never called
- Conditional branches untested

**Your Task:**
1. Explain coverage gap analysis process
2. Identify common gap patterns
3. Design tests for each gap type
4. Provide test templates
5. Show how to reach 100% coverage

**Expected Output:**
- Gap analysis methodology
- Common gap patterns with examples
- Test templates for each pattern
- Coverage enforcement configuration
- Steps to reach and maintain 100%
